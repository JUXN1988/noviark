# Security policy / Política de seguridad

## Reporting a vulnerability
Please **do not open a public issue** for security problems. Use GitHub's private reporting instead:
**Security → Report a vulnerability** in this repository. We will reply as soon as possible and credit you if you wish.

## Reportar una vulnerabilidad
Por favor **no abras un issue público** para problemas de seguridad. Usa el reporte privado de GitHub:
**Security → Report a vulnerability** en este repositorio.

## Scope / Alcance
- The desktop app, its key vault and its permission system / La app de escritorio, su bóveda de claves y su sistema de permisos.
- The official installers published in Releases / Los instaladores oficiales publicados en Releases.

Never share your `claves.vault` file or your API keys, including in issues or screenshots.
Nunca compartas tu archivo `claves.vault` ni tus API keys, tampoco en issues o capturas.
