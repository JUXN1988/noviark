# Noviark roadmap / Hoja de ruta

Dates are targets, not promises. Enterprise customers help prioritize.
Las fechas son objetivos. Los clientes Enterprise ayudan a priorizar.

## ✅ v4.2 — Solid foundation / Base sólida (2026 Q3)
- Autonomous agent with 38 tools; planning brain with an approvable plan / Agente autónomo con 38 herramientas; cerebro planificador con plan aprobable
- 20+ providers with live verification; multi-key rotation; automatic fallback / 20+ proveedores verificados; rotación de claves; respaldo automático
- Local AI tuned to hardware; load/think timers / IA local ajustada al hardware; tiempos de carga y razonamiento
- Tests with self-repair; secret scanner; restore points / Pruebas con autocorrección; escáner de secretos; puntos de restauración
- Parallel projects, continuous learning, PC control, scheduled tasks / Proyectos en paralelo, aprendizaje continuo, control del PC, tareas programadas
- Native app on Windows, Ubuntu and macOS; English and Spanish / App nativa en 3 sistemas; inglés y español

## ⏳ v4.5 — Enterprise-ready / Listo para empresa (2026 Q4)
- Code-signed installers (Windows Authenticode, Apple notarization) / Instaladores firmados
- Automatic updates / Actualizaciones automáticas
- First-run assistant and project templates (web, API, desktop, mobile) / Asistente de primer uso y plantillas
- Allowed-model policies from a config file / Políticas de modelos permitidos
- Better built-in code editor and one-click version history / Mejor editor e historial de versiones

## v5.0 — Team platform / Plataforma de equipos (2027 Q1)
- Admin console, SSO (SAML/OIDC), audit log of every agent action / Consola de administración, SSO, auditoría
- Managed on-premise AI server / Servidor de IA gestionado on-premise
- Shared workspaces and per-seat licensing / Espacios compartidos y licencias por puesto

## v5.5 — Beyond code / Más allá del código (2027 Q2)
- Agents for documents, spreadsheets and office workflows / Agentes para documentos, hojas y oficina
- Git, GitHub and CI integration; one-click deploy / Integración Git/GitHub/CI; despliegue en un clic
- MCP connector catalog / Catálogo de conectores MCP

## v6 — Own models / Modelos propios (2027 Q3+)
- Compact models fine-tuned by Noviark Labs for local coding / Modelos compactos afinados para programar en local
- Mobile app to supervise agents / App móvil para supervisar agentes
